# Test Directory Structure
- `crypto/`: Web Crypto API unit tests (AES-GCM, RSA-OAEP, ECDSA, PBKDF2)
- `qr/`: MLO1 protocol framing, chunking, CRC32, and frame assembly tests
- `db/`: IndexedDB schema, store queries, and transactional ACIDity tests
- `unit/`: Component and utility unit tests
- `e2e/`: Full offline referral journey simulation tests
